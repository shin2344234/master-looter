Plants, ore, stone and wood are collected on a fresh install. They were not before.

- Gather nodes are identified by the prefab they were placed from, matched against a table of 1,042 node kinds built from the game's own data and compiled into the plugin. A node used to be known only once you had gathered one of its kind by hand, so on a new install every plant and every ore vein was skipped as unidentified. Thanks to LuxDragon for the report and the log that made this findable.
- The number a node reports for itself is not the same from one session to the next, so a remembered pairing could file a node under the wrong switch: the id that meant Shrubby Sophora one evening meant a sweet potato patch the next. Nothing is remembered after you quit, MasterLooter.learned.tsv is deleted, and what the mod works out from your bag now lasts only the session.
- A node whose id happened to match an item row could be treated as that item. Gather ids and item ids are now kept apart.
- The Nearby tab and the log name a node instead of showing a number.
- Presets. Every setting and every class, tag and item rule saved under a name in a MasterLooter.presets folder, swapped in two clicks from the General tab. Load one, change what you like, then Save over it. Copy the folder to keep your presets across a reinstall.
- Backups. One is written each time the game starts, before anything can change your settings, and a migration leaves one of its own. Pick any of the last twelve from a list and restore it, so a version with different defaults is a click to undo.
- Everything that overwrites or discards asks first: saving over a preset, replacing a backup, restoring one, deleting either. Loading a preset does not ask, since loading another puts it back.
- A notice when the bag is full, showing slots used against slots available, the moment it fills rather than only while you are looting. If a game patch moves the fields it reads, the mod falls back to noticing that pick-ups have stopped landing. Turn it off under General.

Built for Crimson Desert 2.01.00 (exe 1.0.0.2760). Source and issues: https://github.com/shin2344234/master-looter
