For Crimson Desert 2.01.00 (exe 1.0.0.2760).

Turning frame generation on or off no longer crashes the game.

## The crash

Fyreon87 reported that flipping frame generation in the game's settings killed
Crimson Desert, and only with this mod loaded. They found it by bisecting their
load order for an hour and a half, ran the mod on its own, ran everything except
the mod, and reproduced it on two versions.

It could not be reproduced here, so it was reproduced on a borrowed machine with
a card that has frame generation, where it happened every time within a couple
of minutes of a toggle.

The mod wraps the game's swapchain so the menu can draw. Wrapping that also
means holding a reference to every back buffer, because that is what drawing
into them requires. Toggling frame generation destroys the swapchain and builds
a new one, and the mod was still holding those buffers while the game tried to
take them apart. The game then read a null pointer, twice, and went.

Letting go of the buffers before the swapchain is destroyed is the whole fix.
Every other place in that file already did it. The teardown was the one that did
not.

The menu keeps working across a toggle. Six swapchain rebuilds in one session,
five of them frame generation going on and off, with the menu opening before and
after.

## Also fixed

The loot engine only started once the game had drawn a frame. Where another mod
had already hooked the same DirectX function and the swapchain wrapper was off,
no frame ever reached the mod, so it loaded, reported its hooks, and then did
nothing at all for the session without a word about why. Looting has nothing to
do with drawing and no longer waits for it.

File properties said version 1.3.0. They had said that since 1.3.0, so 1.4.0,
1.5.0, 1.5.1, 1.6.0 and 1.6.1 all shipped telling Windows the wrong number. They
are built from the real version now.

A fault inside the mod used to take the game down without writing anything, which
made a crash report almost useless. Faults are caught and named in the log now,
with the address and the module, and the game keeps running.

## Known

The menu does not appear while frame generation is on if another mod has already
hooked the DirectX present function. There is nothing left for the mod to draw
through in that case, and it now says so in the log rather than going quiet.
