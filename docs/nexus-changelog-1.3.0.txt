For Crimson Desert 2.01.00 (exe 1.0.0.2760).

Ore veins are mined for you now, and Simplified and Traditional Chinese ship with
the mod.

## Ore

A vein used to be emptied: the mod lifted the ore straight out of the node. That
skips the drop, and the drop is the only place the game applies your tool's
Mining Yield Up, so a better pickaxe counted for nothing.

The mod now breaks the vein instead, sending the game the same break it raises
for itself when you swing. The contents spill on the ground and get picked up
from there, with the tool bonus applied by the game rather than imitated. Each
vein is struck once and left alone until the game brings it back.

Veins are also reached for as far out as the scan can see. They take seconds to
answer where a bush takes a fraction of one, so asking only once you are standing
on one meant it opened too late to be any use.

Arming was broken from the beginning and nobody could have seen it. The routine
writes to a named trigger and silently does nothing when the name is not one the
node carries; the mod had been reusing a single name it overheard once, which no
node in a whole session's capture actually held. It now reads the names out of
the node itself. Nothing armed correctly before this, including trees.

## Ownership

The check that decides between Take and Steal now arms the moment there is a
player, instead of waiting for the game to run its own. 1.2.1 added that and it
never once ran: its only caller sat at the very bottom of the verdict, reached
only for something already about to be looted, so a session where nothing got
that far never armed at all. Two logs show it firing 57 and 76 seconds into play,
and nothing could be looted until then.

## The node table

Rebuilt. A bug in the generator was dropping 6,539 of the game's 13,906 gimmick
rows, 47 per cent, because a prefab path came back with the next field stuck to
its tail. 212 gather nodes the mod had never seen are in the table now.

Ore was also wrong: only 20 of 161 rows carried the game's own mine tag and the
rest were guessed from the prefab name, badly enough that "ore" inside "core" and
"store" pulled in shop counters, copper pipework, a fountain and six abyss puzzle
platforms. The guess is gone and all 71 ore rows are ones the game itself tags.
Every row now records where its kind came from.

Arming also refused to leave puzzle mechanisms alone. The verdict has always
skipped memory triggers, quest objects and fast-travel artifacts, but arming
applied none of that and was seen poking an abyss artifact.

## Furniture, rock, wells

Furniture is furniture whether it is standing or lying on the floor. The switch
only ever governed nodes whose prefab happened to contain the word, so tables
were picked up with it turned off. It now reads the item's class, which covers
all 123 pieces from a one-copper table to a twelve-thousand-copper carpet.

A prefab that turns down arming four times over stops being reached for across
the field and gets the ordinary range. The rock nodes had taken 41 arm calls
across 13 nodes without once answering.

The well bucket is recognised by where it lives rather than by a runtime type id.
Those ids change between sessions, so the number written into the mod matched a
well on the day it was written and something arbitrary since.

## Chinese

Simplified and Traditional, translated by dofo7777, built into the plugin so they
work under a mod manager that deploys the .asi on its own. A button each under
General, Language. A file of the same name beside the plugin still wins, so a
correction does not need a release.

The translation template was also wrong: the collect switches, the class groups,
the key rows and the whole Status tab never reached it, so a translator could not
have covered them. 92 strings were invisible.

## Also

- The Nearby list shows an object's class, value and tags on hover, so the rule
  that would change a verdict can be read off the row instead of guessed at.
- A node is named from the prefab table before it holds anything, so the log says
  "Mine iron node" rather than a path.
- Ore veins no longer wait to fill before the mod acts on them. The gather event
  carries nothing but the target's id, so there was never anything to wait for.

Thanks to dofo7777 for the Chinese, and to lzmbrow and LuxDragon for the reports
that led to the ownership and ore work.
