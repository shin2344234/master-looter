[size=4][b]1.6.4: the mod can finally tell one creature from another[/b][/size]

Set Item_Tench to never on the Items tab and tenches get left in the water while
everything else is still caught. Same for a Camel Cricket, a Ricefish, an Iguana.
This is the thing LuxDragon asked for back when ground lizards became catchable,
and it needed something found this morning to work at all.

Until today the mod guessed what a creature was by hunting through its memory for
a species word in a model name. Fish all show up as "cd_fish", and the small
insects as "cd_effectmonster_normal". Twelve sessions of logs, three species
named correctly. Every rule you set on a creature was being skipped in silence.

The creature had been carrying the answer all along, two bytes into its status
block: a row number into the game's own character table. Full account, including
the two probes that found nothing because of my own bugs, is on GitHub:

https://github.com/shin2344234/master-looter/blob/main/docs/ore-investigation/CREATURES.md

[size=4][b]Also[/b][/size]

Installing a hook had a window, a few instructions wide, where a game thread
could call through nothing at all. Narrow, but these go in while the world is
loading and one of them sits on a function that runs thousands of times a second.

An old settings file was being migrated on every launch instead of once, which
reverted a hand edit each start and pushed your real backups out of the list.
Presets and restored backups change the menu language now. The log names whatever
hooked DirectX before this mod did, rather than saying only that something had.

[size=4][b]The crash I did not fix[/b][/size]

lsimo's fast travel crash is still open. The fix I shipped for it was aimed at
queued work outliving a teleport, and the queue turns out to empty within a
millisecond, so there was never anything there to go stale.

So this release adds a way to catch it instead. If the mod faults while driving
one of the game's state machines, the log now records what that object looked
like an instant earlier, including the class it names through its vtable. A live
object names itself; a freed one cannot. The next report settles it.
